# Hotel Booking Data Analysis Project 🏨📊

A comprehensive exploratory data analysis (EDA) project utilizing **Python**, **Pandas**, and **NumPy** to clean, process, and extract meaningful insights from hotel booking datasets.

## 🚀 Project Overview
This project focuses on analyzing customer booking behaviors, trends, pricing dynamics, and stay patterns within a large hotel dataset containing over 119,000 rows. The objective is to demonstrate core data manipulation capabilities and analytical problem-solving skills using modern Python data science libraries.

## 🛠️ Key Skills & Techniques Applied
- **Data Cleaning & Preprocessing:** Handling missing values (e.g., dropping columns with high null rates like `company`) and inspecting dataset structures (`shape`, `info`, `isnull`).
- **Feature Engineering:** Creating custom derived columns to calculate total stay duration, total expenditure (`adr * nights`), and combined guest demographics.
- **Advanced Grouping & Aggregation:** Utilizing sorting (`sort_values`), filtering (`between`, boolean masking), and frequency counting (`value_counts`).
- **Custom Functions & String Operations:** Applying custom Python functions combined with Pandas `.apply()` method to process phone area codes and names.

## 📈 Key Insights & Findings
- **Missing Data Management:** Identified and dropped unneeded sparse columns to maintain structural integrity.
- **Pricing & Stays:** Calculated average daily rates (ADR) and total stay costs across diverse customer profiles.
- **Guest Demographics:** Analyzed repeat guest percentages (~3.19%) and identified top country codes and family structures[span_9](start_span)[span_9](end_span)[span_10](start_span)[span_10](end_span)[span_11](start_span)[span_11](end_span).
